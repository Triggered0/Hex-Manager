# Hex-Manager

Modular Hextech plugin suite for the League of Legends Client (Pengu Loader).

## Features

- **Auto Accept:** Instant (0s) or delayed ready-check accept with audio safety hooks.
- **Champ Select Dodge Button:** Single-click dodge across all queues (custom & matchmade) without closing the client via SGP logout.
- **Auto Rune, Spells & Item Sets Importer:** Automatic OP.GG / U.GG builds and item sets in Champion Select.
- **Player Analysis Popup:** Match history, win rates, premade detection, and performance scoring in Lobby, Champ Select, and In-Game.
- **Mode Balance Info:** ARAM / special mode buff and nerf tooltips.
- **Auto Lock Champion & Auto Queue:** Automated pick/ban and post-game requeue.
- **Auto Honor:** Post-game honor automation based on performance scoring.
- **Arena God Tracker:** Track Arena wins across all champions.
- **Profile, Social, Window & Mode Tweaks:** Custom rank/background/status, 5v5 Practice Tool bots, Name Spoofer, Whale Helper, Use Client In Game, and Penalty UI Suppress.

## Installation

Place the `Hex-Manager` folder inside `C:\Program Files\Pengu Loader\plugins\Hex-Manager`.
Press **F1** or click the **HEX** button in the top-right client navigation bar to open the Command Center.
